# BookNest

BookNest is a static website for the university library. It helps KAU students check which books are available, reserve books online and remember when to pick them up, so they do not waste a trip to the library or wait in line at the desk.

**Course:** CPIS 358 – Internet Applications & Web Programming (Fall 2026, Section IS1)
**Group:** Dinosaurs – Jawad Bukhari and Mohammed Almoraie

## Pages

| Page | What it has |
|------|-------------|
| `index.html` | Home page: the problem, benefits, Book of the Day, book search and reservation list |
| `login.html` | Student login form with JavaScript validation |
| `signup.html` | Sign up form with validation and a password strength bar |
| `about.html` | Our idea, goals, opening hours, FAQ and team |

## Main features

- **Assignment 1 (HTML & CSS):** master page with a shared menu, image map on the logo, lists, tables, forms, internal links, inline / internal / external CSS, general classes, z-index layering, shadows and borders.
- **Assignment 2 (JavaScript):**
  - Book of the Day slideshow (dynamic picture and text)
  - Search the books table by title, author or category
  - Reserve up to 3 books (list items created with JavaScript)
  - Login and sign up form validation with red/green fields
  - Password strength bar and Caps Lock warning
  - Dark mode that is remembered between pages
  - FAQ built with JavaScript and a Back to top button

## How to run

Download or clone the repository and open `index.html` in any web browser. No server or installation is needed.
